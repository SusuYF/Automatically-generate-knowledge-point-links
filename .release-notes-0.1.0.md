First release.

## What it does

Generates a knowledge-point-level navigation block at the top of an Obsidian note.
Unlike a table of contents, which copies your headings, each link's display text is
a distilled knowledge point, and the anchor points at the section it came from.
Hover a link to preview that section without losing your place.

## Install

1. Download `main.js`, `manifest.json`, and `styles.css` from the assets below.
2. Put them in `<your-vault>/.obsidian/plugins/knowledge-nav/`.
3. Reload Obsidian and enable **Knowledge Nav** in Settings → Community plugins.

## Setup

Open **Settings → Knowledge Nav** and fill in an API base URL, an API key, and a model
name. Any OpenAI-compatible endpoint works — DeepSeek, Moonshot, Zhipu, SiliconFlow,
Ollama (`http://localhost:11434/v1`), or OpenAI itself. Press **Test** to confirm the
three line up before using it on a note.

## Network use

This plugin sends the text of the note you run it on to the LLM endpoint you configure.
No other notes, no vault metadata, no telemetry of any kind. Your API key is stored in
the plugin's `data.json` inside your vault, in plain text. Nothing is written to the
vault until you accept the preview.

## Known limitations

- **Links jump to the section, not the exact line.** Several knowledge points under one
  heading lead to the same place. Deliberate trade-off: precise jumping would require
  block IDs on individual lines, which makes the note source much noisier. Requires the
  core **Page preview** plugin for hover navigation.
- **Output quality depends on the model.** Small local models produce noticeably worse
  nav blocks. The validation report catches structural breakage, not weak knowledge points.
- **One API call per note**, billed by your provider.
- **Heading insertion modifies the note body** when a long note has almost no subheadings.
  Only heading lines are inserted — the plugin verifies this after writing.
- **Markdown notes only.** No Canvas, no PDF.

## Verified

29 unit tests pass. End-to-end tested against a real LLM on three fixture notes
(well-sectioned, flat-and-long, and very short); all three produce valid navigation.
